# Web Site Route

Лендінг для сервісу планування маршрутів.

## Запуск

Відкрийте `index.html` у браузері або запустіть локальний сервер:

```powershell
python -m http.server 8000
```

Після цього сайт буде доступний за адресою `http://localhost:8000`.

## Структура

- `index.html` - розмітка сторінки
- `styles.css` - адаптивні стилі
- `script.js` - меню та обробка форми
- `assets/hero-route.png` - hero-зображення
