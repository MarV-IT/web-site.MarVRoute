# MarV Route Landing Page

Landing page for the MarV Route mobile app (Flutter): automatic trip detection, trip review,
Work Mode, an IRS standard-rate mileage estimate (US) and a kilometer log (Canada), fuel and
expense logging, PDF/CSV reports,
maintenance reminders, cloud backup, and Pro features.

## Запуск

Відкрийте `index.html` у браузері або запустіть локальний сервер:

```powershell
python -m http.server 8000
```

Сайт буде доступний за адресою `http://localhost:8000`.

## Структура

- `index.html` — головна сторінка (hero з мокапами екранів Home/Reports, фічі, how it works,
  ставка IRS для США та журнал кілометрів для Канади, галерея скріншотів, звіти, Pro, FAQ,
  форма підписки на запуск)
- `privacy/index.html` — політика конфіденційності, доступна за `/privacy`
- `terms/index.html` — умови використання, доступні за `/terms`
- `support/index.html` — сторінка підтримки, доступна за `/support`
- `delete-account/index.html` — видалення акаунта, доступне за `/delete-account`
- `styles.css` — адаптивні стилі + темна тема (`:root[data-theme="dark"]`)
- `script.js` — переклад EN/UK, перемикач теми, анімації появи, обробка форми (головна сторінка)
- `legal.js` — переклад EN/UK/FR і перемикач теми для сторінок `/privacy`, `/terms`,
  `/support` та `/delete-account`
- `assets/marv-route-icon.png` — іконка додатку (favicon, apple-touch-icon)
- `assets/og-image.png` — 1200×630 картинка для соцмереж (Open Graph / Twitter)
- `assets/screens/*.png` — справжні скріншоти додатку (540×1200, знято на емуляторі Pixel 6)

## Що треба зробити перед публікацією

1. ~~**Правила Firestore для форми.**~~ ✅ **Зроблено 29.07.2026** — форма працює
   на живому сайті, заявки долітають до Firestore.

   Заявки з форми пишуться у колекцію `leads` Firebase-проєкту
   `route-mint-app-2026` через REST API (без SDK). Чинні правила безпеки:

   ```
   match /leads/{leadId} {
     allow create: if request.resource.data.keys()
                        .hasOnly(['name', 'email', 'driverType', 'language', 'createdAt'])
                   && request.resource.data.name is string
                   && request.resource.data.name.size() > 0
                   && request.resource.data.name.size() <= 100
                   && request.resource.data.email is string
                   && request.resource.data.email.size() <= 200
                   && request.resource.data.email.matches('^[^@]+@[^@]+[.][^@]+$')
                   && request.resource.data.driverType is string
                   && request.resource.data.driverType.size() <= 100
                   && request.resource.data.language in ['en', 'uk']
                   && request.resource.data.createdAt is timestamp;
     allow read, update, delete: if false;
   }
   ```

   Що роблять правила: дозволяють будь-кому **лише створити** запис і лише
   з цими п'ятьма полями та обмеженнями довжини. Читати, змінювати й видаляти
   з клієнта не можна взагалі — заявки видно тільки вам у Firebase Console.

   Перевірено на живому сайті (усе, крім першого рядка, має відхилятися):

   | Спроба | Результат |
   | --- | --- |
   | Коректна заявка | ✅ 200 |
   | Зайве поле (`isAdmin`) | 🚫 403 |
   | Невалідний email | 🚫 403 |
   | Порожнє ім'я | 🚫 403 |
   | Мова поза `en`/`uk` | 🚫 403 |
   | Ім'я 500 символів | 🚫 403 |
   | Читання колекції `leads` | 🚫 403 |
   | Читання чужих `backups` | 🚫 403 |

   Ключ `FIREBASE_API_KEY` у `script.js` — це публічний клієнтський ключ Firebase.
   Він ідентифікує проєкт і **не дає доступу**: доступ визначають саме правила вище.

   Що вже вбудовано у форму:
   - валідація імені, email і галочки згоди;
   - honeypot-поле проти спам-ботів (приховане, боти його заповнюють — заявка тихо відкидається);
   - поле `language` — якою мовою людина дивилась сайт;
   - `createdAt` — час заявки;
   - стани «надсилаємо / успіх / помилка», які перекладаються при зміні мови;
   - причина збою пишеться в консоль браузера (`[MarV Route] signup failed: …`).

   **Де дивитись заявки:** Firebase Console → Firestore Database → колекція `leads`.
   Листів на пошту не буде — за потреби це окремо налаштовується через
   Firebase Extension «Trigger Email» або Cloud Function.

## URL-структура

Сторінки лежать у власних теках з `index.html`, тому адреси чисті, без `.html`:

| Сторінка | URL |
| --- | --- |
| Головна | `www.marvroute.com/` |
| Політика конфіденційності | `www.marvroute.com/privacy` |
| Умови використання | `www.marvroute.com/terms` |
| Підтримка | `www.marvroute.com/support` |
| Видалення акаунта | `www.marvroute.com/delete-account` |

Це працює на будь-якому статичному хостингу (Netlify, Vercel, GitHub Pages, Cloudflare Pages)
і на локальному `python -m http.server` без додаткових налаштувань. Обидві адреси —
з кінцевим слешем і без нього — віддають сторінку.

Внутрішні посилання вказують на чисті шляхи (`privacy/`, `../`), тому в адресному
рядку ніколи не з'являється `index.html`.

Щоб сайт при цьому лишався придатним для відкриття подвійним кліком з диска,
у `script.js` і `legal.js` є дві невеликі функції:

- `fixFileProtocolLinks()` — під `file://` дописує `index.html` до посилань на теки
  (без сервера браузер не вміє робити це сам). Викликається після кожного рендера,
  бо переклад може заново вставляти посилання.
- `canonicalizeUrl()` — якщо користувач усе ж потрапив на `/index.html` (стара
  закладка, надіслане посилання), прибирає його з адресного рядка через
  `history.replaceState`, без перезавантаження.

Посилання на `/privacy` потрібне для сторінок додатку в Google Play і App Store,
`/support` — обовʼязкове поле «Support URL» в App Store Connect.

## Мови

- Головна сторінка — англійська й українська (`script.js`).
- Юридичні сторінки — англійська, українська й французька (`legal.js`). Французька
  потрібна для користувачів із Квебеку: договір приєднання і політика мають бути
  доступні французькою.
- `?lang=fr` (або `en`, `uk`) в адресі юридичної сторінки відкриває її потрібною мовою,
  наприклад `https://marvroute.com/terms/?lang=fr`. Так на документи посилається додаток.
- Вибір мови зберігається в `localStorage` (`marv-lang`) лише тоді, коли відвідувач сам
  натиснув перемикач або прийшов за посиланням із `?lang=`.

Французької на головній поки немає з технічної причини: правило Firestore для колекції
`leads` приймає в полі `language` тільки `en` або `uk`. Щоб додати французьку на головну,
спершу змініть у правилах `request.resource.data.language in ['en', 'uk']` на
`in ['en', 'uk', 'fr']`, а потім додайте блок `fr` у `script.js` і `"fr"` у `SUPPORTED_LANGS`.

## Податкові тексти

- **США.** Сума на сайті й у додатку — це *оцінка* відрахування за стандартною ставкою IRS.
  Поруч завжди має бути застереження «estimate, not tax advice». За стандартної ставки
  пальне й ремонт окремо не відраховуються, паркування і платні дороги — відраховуються.
- **Канада.** Самозайняті водії заявляють фактичні витрати на авто пропорційно частці
  робочих кілометрів. Покілометрові ставки CRA ($0.73/$0.67 у 2026) — це межі компенсацій
  від роботодавця, а не відрахування, тому на сайті їх немає: для Канади — лише журнал
  кілометрів, без суми.
- Формулювань на кшталт «tax-ready», «every deduction counted», «tax savings» слід уникати.

## Форма і лист про запуск

Текст згоди біля галочки і рядок «Sender» під нею разом виконують вимоги CASL до запиту
згоди: хто просить (MarV Space), навіщо (один лист про запуск), поштова адреса та email,
і що згоду можна відкликати. Галочка не має бути відмічена заздалегідь.

Сам лист про запуск має містити: назву відправника, цю ж поштову адресу, зрозумілу тему,
а також робочий спосіб відписатися. Відписку треба виконати протягом 10 робочих днів
(CAN-SPAM); закон Айдахо про масові листи (Idaho Code § 48-603E) дає на це 5 робочих днів,
тож орієнтуйтеся на 5. Після розсилки заявки з колекції `leads` слід видалити — так обіцяє
Політика (розділ 4).

## Політика ↔ код додатку

Політику звірено з `Route-Mint-App` (коміт 2f7c702):

- аналітичних SDK немає (`help_analytics.dart` лише пише в debug-лог);
- гостьовий режим без хмари; вхід через email/пароль і Google;
- резервна копія в `users/{uid}/backups/latest`: поїздки без GPS-треків, витрати, пальне,
  налаштування Робочого режиму і всі налаштування додатку — зокрема ім'я, назва бізнесу,
  дані авто (номерний знак, одометр), страхування та бухгалтера;
- копія створюється автоматично раз на добу, коли користувач увійшов в акаунт і має Pro
  (зараз — безкоштовний перемикач Tester Pro); окремої кнопки «видалити копію» немає —
  копія зникає разом з акаунтом або за запитом на пошту;
- дозволи: геолокація, сповіщення, виняток з оптимізації батареї; дозволу на сховище немає;
- авто-визначення тримає GPS високої точності ввімкненим увесь час, поки воно активне;
- карти з `tile.openstreetmap.org`, геокодування через пакет `geocoding`;
- PDF/CSV, хмарна копія, авто-визначення, підсумки пального, чекліст місяця і нагадування
  про обслуговування — функції Pro (`EntitlementService`).

Якщо щось із цього зміниться (наприклад, події почнуть кудись надсилатися або з'явиться
платна підписка), спершу оновіть Політику, Умови й форму Data safety.

Ставки IRS на сайті збігаються з `TaxService`: 72,5¢ до 30.06.2026 і 76¢ з 01.07.2026.
